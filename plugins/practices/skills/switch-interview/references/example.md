# 切换访谈的一对输入输出

## 输入（主人带来的需求）

> 客服主管 C 找我说：「工单系统要支持按标签批量关闭」。我下午去问 C。

## 输出（备问题）

```
原话｜工单系统要支持按标签批量关闭（提：客服主管 C）
断言（假设）｜真正的问题是大促后成批的重复工单要一个个手点关闭，不是「缺一个批量按钮」
问 C｜1 上次遇到这种情况你们怎么办的？ 2 现在怎么忍过来的？ 3 不做会怎样？
```

## 输入（答案回来）

> 上次：上个月大促后有三百多个「物流查询」的重复工单，两个客服手工点了一下午。
> 现在：每周一早上一个客服花一小时把上周的重复单清掉。
> 不做：就继续这么清。不过下季度要考核工单关闭时效，这些单会把时效拖垮。

## 输出（读答案）

```
推力｜「两个客服手工点了一下午」「每周一…一小时」——重复工单一直在手工清，活没少过
    ｜「下季度要考核工单关闭时效，这些单会把时效拖垮」——考核一来，现状撑不住
拉力｜未提到（C 没说批量关闭好在哪、能省掉哪一步）
焦虑｜未提到
习惯｜「就继续这么清」——现状能撑，撑到考核那天
断言｜原写：成批的重复工单要一个个手点关闭。
    ｜裁为：重复工单每周靠一小时手工清，下季度考核关闭时效后这批单会把时效拖垮；「一个个手点」是每周一小时，量比原想的小，压力在考核
```

要点：问题只问过去；四种力每条指到一句原话，没有的写「未提到」；答案里没说的（比如「批量关闭能省掉那一小时」）不替提出方补；改断言时旧句留着。
