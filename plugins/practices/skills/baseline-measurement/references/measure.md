# 测量的形状

```
数｜量什么 → 进决定：<哪个决定>；规则：<超过多少就怎样>
条件｜请求样本：<哪一条>；环境：<哪个>；工具与指标：<什么>；预热与次数：<都一样>
老路径｜命令：<原样>；结果：<数，或「待主人跑」>
新路径｜命令：<原样>；结果：<数，或「待主人跑」>
判定｜<按规则给出>，或「数回来后按规则定」
```

## 例子：命令行笔记工具换索引后 `notes search` 慢多少

```
数｜`notes search 会议` 的耗时差 → 进决定：新索引要不要默认开；规则：新的比旧的慢超过 100 ms 就先不默认开
条件｜请求样本：同一个关键字「会议」、同一份 3000 文件的笔记目录；环境：主人的台式机；工具与指标：`hyperfine --warmup 3 --runs 10`，看均值；两边都跑 10 次
老路径｜命令：`hyperfine --warmup 3 --runs 10 'notes search 会议'`；结果：待主人跑
新路径｜命令：`NOTES_INDEX=sqlite hyperfine --warmup 3 --runs 10 'notes search 会议'`；结果：待主人跑
判定｜数回来后按规则定
```
