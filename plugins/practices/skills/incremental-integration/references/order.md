# 接入顺序

## 形状

```
顺序｜1 <表或配置扩>（退：<一句>）→ 2 <开关注册，关>（退：<一句>）→ 3 <合代码>（退：<一句>）→ 4 <下游>（退：<一句>）→ 5 <上游>（退：<一句>）→ 6 预发联调
联调｜<已否过的哪条新例子沿哪条链跑，期望什么>；老路径：<哪条例子，期望不变>；<共库只读 / 可写>
之后｜放量与回滚点归第 8 阶段；删旧表另起一步放在放量之后
请否顺序；哪步退不了直接说。
```

## 例子：区域加价从按大区改成按省份

```
顺序｜1 建 province_surcharge 表，region_surcharge 不动、报表任务照读（退：新表留着不用）→ 2 注册开关 surcharge_by_province，关（退：删注册）→ 3 合代码（退：开关关着即老路径）→ 4 预发联调
联调｜模板 1032 新疆 3.2kg 走 OrderService 全链，期望 26；老路径：模板 2001 广东走 BatchCalc，期望不变 18；预发与生产共库，只读
之后｜放量三档与回滚点归第 8 阶段；报表任务迁到新表、删 region_surcharge 各另起一步，放在放量之后
请否顺序；哪步退不了直接说。
```
