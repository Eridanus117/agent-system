# 发布方案：一个例子

形状五行：改动、放量、回滚、观测、冒烟，末尾只留一件要主人定的事。对象用主人原话里的，代替占位符。

## 输入

改动：运费计算加「偏远附加按省份查表」；开关 `remote_fee_by_province` 在配置中心，支持白名单（模板 id）与百分比；老路径 diff 为零已静态验。需求句两条（例：模板 1032、新疆、3.2kg、vip → 26；模板 1032、广东、3.2kg → 18）。测试模板 9001 是内部的。老路径监控有 p99 延迟、QPS、错误率、线程池占用。

## 输出

```
改动｜偏远附加按省份查表（分流条件：模板配置了偏远省份表；开关：remote_fee_by_province）
放量｜档 1 白名单只放测试模板 9001，停半天 ｜ 档 2 百分比 5%，停一天 ｜ 档 3 全量，看满一个完整业务周期再收口
回滚｜任一档异常，关 remote_fee_by_province；前提：calc 老路径 diff 为零已静态验
观测｜「省份在表中时加附加」→ 新路径命中数、抽 20 条与例子比对 ｜「不在表中不加」→ 新路径异常数 = 0 ｜ 老路径四个黄金信号：p99 延迟、QPS、错误率、线程池占用不变
冒烟｜档 1 放开后用模板 1032 新疆 3.2kg vip 打一条，期望 26
请你定档 1 放谁；每档放开和进下一档我都等你。
```

只有开／关两档的环境（进程级环境变量）：放量那行写「关 → 开一次跑验证例子 → 开」，并写明退化的原因。
