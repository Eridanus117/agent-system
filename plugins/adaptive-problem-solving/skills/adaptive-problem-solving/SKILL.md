# 自适应问题求解

管理“当前如何理解和解决问题”。本文件只保留所有路径共用的薄控制循环；分支协议按命中条件从 `references/` 加载，方法、知识、任务状态、研发记忆和工具能力仍归各自载体。

## 一、进入或退出

以下任一情况出现时进入：

- 用户要求重新界定、检查方向、选方法或复盘；
- 问题、结果或关键约束仍有多种会显著改变结果的解释；
- 准备选择第一项实质路径，且选错会造成明显返工；
- 准备进行多来源调研、高成本实验、难回退操作或共享状态修改；
- 新证据推翻关键假设，范围／成本明显扩大，或连续工作未减少关键未知；
- 长任务恢复、重要交接、阶段结束或最终验收；Agent 系统 MVP、工作流替代、父任务或其他长期行为能力进入自然观察或完成判断前必须进入；
- 模型、推理强度、上下文、工具、环境或 Agent 组合会显著影响质量、成本或风险。

普通事实查询、低风险局部编辑、机械格式化和明确易回退步骤走 O0 普通路径，不加载后续 reference。同阶段没有新证据或风险时不重复检查；选择普通路径后，只有说明实质变化才能升级。

## 二、恢复真正的问题

从现有上下文、当前权威和任务状态恢复，不让用户重复已知内容。分开写：

- **原始问题**：什么状态不理想，为何值得处理；
- **期望结果**：什么会变好，如何观察；
- **背景与症状**：帮助理解但不替代问题；
- **用户或 Agent 假设**：待检验的解释；
- **候选方案**：当前想到的做法，不自动升级为需求；
- **约束与授权**：不能做什么，哪些决定仍归负责人；
- **当前阶段**：本次只推进哪一部分。

解释差异会改变方向时先问一个最小问题；否则以可逆假设继续并写明翻转信号。把“最容易继续”与“最能减少关键未知或推进结果”分开，只指出一个主瓶颈。

## 三、归型并选择路径

进入后读取 [`references/method-registry/INDEX.md`](./references/method-registry/INDEX.md)，按 O0、P1–P8 或 U 归型：

1. O0 立即退出到普通路径；U 只取得一条能区分至多两个候选类型的证据，再归型；
2. 普通路径始终有效。只比较选错方向的预期损失、方法可能改善判断的幅度、信息／运行／延迟／维护成本、可逆性和反馈速度、负责人或额外 Agent 的协调成本；
3. ROI 用高／中／低或数量级，不伪造精度。默认优化总周期、有用吞吐和负责人注意力，不把最小 diff、单步快或渐进投入当目标；
4. 只读取与主类型、风险和成本匹配的少量卡片，通常一张主卡；组合时服从索引和卡片上限，不把方法全串起来；
5. M0 只可由用户人工点名，或在明确说明“未验证”后作为建议，不得默认触发；M1 只在与已验收样本相同的边界下建议；
6. 同意、授权、风险、写入所有权和可逆性是硬门。类型命中、索引排序、证据升级或外部方法成熟都不产生额外权限；
7. 只有选择结构化问询且命中 `grilling` 时才加载它，并服从其明示同意与退出合同；索引命中不能绕过同意门；
8. 卡片给出的是方法的进入条件、硬门、成本画像与退出条件，不是执行流程。当前装配内若已有承载该方法执行流程的 Skill，改为路由到它并只保留本卡的进入／退出／成本判断，不自己再走一遍；装配内没有时才按卡片的执行定义直接做。哪些 Skill 在当前装配内由装配声明决定，不由资产存在与否决定；
9. 卡片不可读、冲突或都不匹配时退回普通路径或当前类型的最小必要步骤，如实记录发现性缺口，不临场编造已验证方法。

更完整做法若显著减少返工、确认或串行等待，通常优于反复补丁；若扩张不减少未知或后续成本，就缩小。判据是对原始问题和父目标的净贡献减去总成本。

## 五、配置执行并建立阶段合同

方法选定后，只检查会改变执行的条件：模型与推理强度、必要上下文与权威、外部工具反馈、独立复核或并行协作的净收益、环境／权限／共享资源。没有实际切换能力时记录限制，不声称已经调整。

开始方法或实质行动前，写清与风险相称的最小合同：

- 本阶段要减少的关键未知或要作出的决定；
- 方法、选择理由、必要证据与可接受近似；
- 验证面、成本上限、停止／升级／降级／换路条件；
- 产物、完成定义、验收方式和当前授权边界。

低风险任务可隐含表达，不强制制表。方向、授权或长期状态改变时写入任务记录。已经登记迭代事件，或必须跨 Session 恢复因果时，按需加载 `self-improvement` 的 `references/iteration-receipt.md`，只把增量证据写回当前唯一回执；普通任务不为格式完整创建回执。

## 六、行动、反思与验收

首次实质行动前运行 [`pre-action-gates.md`](./references/pre-action-gates.md) 的 G1；形成负责人动作前运行 G2；只有 G2 证明真实阻塞后才可运行 G3 并评估 CF-6。未命中后两条分支时不要预加载其下游合同。

一个真实工作波次为常规周期；无波次的长任务只在重要阶段结束取样。纠正、重复失误、能力回退、抽象循环或预注册翻转条件即时旁路；墙钟和资源状态不触发，也不建日历调度或自动化。短查原始目标、关键假设、实际结果与来源，指出最重要偏差、当前主瓶颈、下一行动和停止条件。当前问题或方法由本 Skill 换路；跨任务行为缺口转 `self-improvement`。据此继续、换路或退出；方向未变不生成固定报告。连续两波反思成本高于发现或避免返工的收益，就退回按需模式；只有新证据才能再次常规化。

普通、低风险、容易回退且不改变长期行为的任务到此结束。长程能力、父任务、工作流替代或最终验收必须加载 [`milestone-acceptance.md`](./references/milestone-acceptance.md)，不得用子任务、计划或文件完成替代父目标与产品证据判断。

## 七、负责人决定与返回

先执行 G2。产品目标／长期边界、授权扩大／共享系统修改／明显损失差异、证据不足却必须作高影响决定，以及人的偏好、业务信息或风险承受能力，只有确实改变 G2 五维之一时才进入现有负责人决定协议；它形成问题、少量选项、推荐、收益／代价和普通路径，本 Skill 不复制协议。沉默不是授权。

阶段完成后：

- 目标、授权、决定、进度和下一步进入任务状态；
- 只有有效且通过准入的结论进入知识；
- 纠正、失败、实验和方案理由进入任务证据或研发记忆；
- 可跨任务复用的行为缺口进入 `self-improvement`；
- 协作或未参与者只读复核由 `orchestrated-collaboration` 与真实后端提供所有权、派发和通信；
- 权威变更须由负责人确认。

返回原任务，不把问题求解治理变成长期元项目。
