# 站会记录

一件事停下时写在绑定 issue 下的评论。词的出处：Scrum Guide 每日站会的三问加阻塞项；栏名按本工作区定。

## 模板

标题带本机时间，四栏顺序不变，各一行；「等你」只写一件需要主人定的事，没有的栏写「无」。

```
### 站会 · YYYY-MM-DD HH:MM
做成了：<可复核的结果>
停在：<现在卡在哪一步>
下一步：<谁做什么>
等你：<需要主人定的一件事>
```

## 例子：第 2 阶段刚走完、主人说先停

```
### 站会 · 2026-09-16 16:10
做成了：spec 已发成 issue #33；ADR 一条「用 restic 不用 borg」；词汇表加「增量快照」。
停在：第 2 阶段收口完成，第 3 阶段跳过（一个会话做得完）。
下一步：主人说行进第 4 阶段；agent 建 worktree、跑基线。
等你：说行进第 4 阶段。
```

读的时候找 issue 下最后一条带这四栏的评论，就是现状。
