# 站会记录

时刻、写在哪、四栏各写什么见 `flow` 正文「站会记录」；这里只放模板与例子。

## 模板

```
### 站会 · YYYY-MM-DD HH:MM
做成了：<可复核的结果>
停在：<现在卡在哪一步>
下一步：<谁做什么>
等你：<需要主人定的一件事>
```

## 例子：第 2 阶段刚走完、主人说先停

```
### 站会 · 2026-09-16 16:10
做成了：spec 已发成 issue #33；ADR 一条「用 restic 不用 borg」；词汇表加「增量快照」。
停在：第 2 阶段收口完成，第 3 阶段跳过（一个会话做得完）。
下一步：主人说行进第 4 阶段；agent 建 worktree、跑基线。
等你：说行进第 4 阶段。
```

读的时候找 issue 下最后一条带这四栏的评论，就是现状。
