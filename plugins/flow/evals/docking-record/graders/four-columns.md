Judge only the shape of the docking record (停靠记录) in the final message. PASS if the record is written out (not merely described) and, under its heading, has exactly four labelled lines in this order and with these labels: 做成了、停在、下一步、等你 — no column renamed, dropped or added.

FAIL if a column is missing or renamed, if extra columns or sections are added inside the record, or if the record is only described rather than written out.
