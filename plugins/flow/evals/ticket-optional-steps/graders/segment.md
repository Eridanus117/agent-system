Judge the opening call anywhere in the final message. PASS if the message states all three: this is 常规变更 (a normal change); the opening object is a 票 (a ticket); work starts at 第 4 阶段 (stage 4, 开工准备). The three may appear in one sentence or spread across the message.

Asking the owner to say 「行」 at the stage-4 gate is expected and does NOT count against the message. A conditional aside such as "if the baseline shows there is no seam, go back to stage 2" does NOT count against it either.

FAIL only if the message names a different kind of request (标准变更 / 查询), names a different starting stage as the place to start now (for example insisting on 第 2 阶段 alignment first), or asks the owner "这次怎么走" instead of stating the call.
