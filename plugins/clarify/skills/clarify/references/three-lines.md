# 三行结论

第 4 步的产物。三行各占一行，名字那格不留空。

## 模板

```
1｜真正的问题：不是「<念头原话>」，而是 <翻译后的问题>（业界叫 <名字>；查过没找到就写「查过，未找到对应名」）
2｜值不值得解：<值得／不值得／先不解> —— <理由，含发生频率与已付代价>
3｜往哪个方向解：<方向>，沿用或参照 <已有解法> —— <排除掉的方向及原因>
```

## 例子

念头原话：「我想写个脚本，每天把微信读书的划线导出到 Obsidian。」

问历史两轮后：上次想找一条划线是三周前，翻了十分钟没找到；平时靠截图存相册，相册里堆了两百多张。

```
1｜真正的问题：不是「写个导出脚本」，而是读过的书里想再看的句子找不回来（业界叫 read-it-later／个人知识管理里的 capture 环节）
2｜值不值得解：值得 —— 每周撞到一到两次，每次翻十分钟，相册里两百多张截图已经没法检索
3｜往哪个方向解：先用微信读书自带的「导出笔记」手动导一次，看够不够 —— 排除自写爬虫（要处理登录态，官方没有接口，维护成本高于收益）
```

主人划改后的留痕，写在那一行下面：

```
2｜值不值得解：值得 —— ……
   原写「先不解，每月一次不值得」，主人改为「值得，最近在写书评，每周都要找」
```
