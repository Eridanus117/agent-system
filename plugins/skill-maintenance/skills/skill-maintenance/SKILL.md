# Skill 维护

只维护已确定由 Skill 承载的行为；不扩权、不降门、不造第二控制器。

## 进入与合同

进入：明确维护请求；或触发／跳过、步骤、硬门、退出、来源、调用者、版本、生成物、发现入口、符合性已有漂移证据。

不进入：普通业务代码、产品文档、非 Skill 测试；不改发布身份或行为的错字／格式（但已发布字节的现行版本规则仍服从）；承载位置未定的纠正返回 `self-improvement`，不替它决定。

问题证据不授权写入、发布、安装、退役；缺授权只读并返回缺口。编辑前绑定：原始行为与可观察成功；触发／输入／步骤／输出／退出；授权、同意、写入所有权、证据等级；生命周期驱动者与本 Skill 角色；证据上限。

盘点主 `SKILL.md`、按需 references、全部调用／返回／reference 边、人类入口、双端 manifest／Marketplace、生成物及唯一命令、版本／生命周期／预算／符合性／发布退役工具；获授权才查安装端。未知就标未知，不从旧仓、旧 Issue 或记忆猜。

## 归型与设计

主类型：轻量文本、行为修正、结构重构、新能力、迁移／重命名、退役。新能力查净价值、误触发、预算、发现入口；迁移要求所有调用者 clean cutover；退役要求无入边、负责人批准、精确卸载回读。实验通过不等于发布或长期证据。

新增／扩张前计算 Skill 数与 `SKILL.md`+references 总字节。默认增加伴随压缩／合并／退役，不以搬 reference、拆 Plugin 或改单文件门洗白。只有负责人显式决定可以提高数量或字节上限；须有稳定记录且只到本次需要，提高一次不授权下一次继续提高。

主 `SKILL.md` 只放共用控制面；reference 仅命中时加载，主文件写命中、读取、返回。一个行为一个正文；调用者只路由；reference 不成为第二个控制器、生命周期驱动者或状态库；路径可定位；人类总览由生成物承载。

## 场景、切换与验证

行为修正、结构重构、新能力、迁移、退役须在编辑前预注册进入、分支／加载、硬门、退出／返回、证据上限；重构以同场景比较基线／候选。授权、明示同意、写入所有权、安全、不可逆动作、证据等级、角色下限是零回退门；漏一项即失败，不能用字节／行数减少或模型多数通过抵消。

影响新能力、核心行为或 description 触发面的变更，读取 `references/evaluation-loop.md`，并用 `evals/evals.json` 注册正例与 near-miss 负例，执行条件化配对评估：新建 Skill 运行 `baseline` 与 `with_skill`，已有 Skill 变更运行 `old_skill` 与 `with_skill`，需要时保留 `baseline`。评估工具只校验和汇总外部结果，不调用模型、不读取凭据，也不证明安装端生效。

实施：先改唯一正文，迁移全部调用者；删除旧路径、章节号、重复段落、别名、兼容壳、过期 re-export；生成物只运行唯一生成命令；已发布内容按生命周期规则递增版本，并同步 manifest、Marketplace、注册表、版本夹具、人类总览；发布、安装、指纹、退役只用已有工具。

先跑最窄检查，再跑完整符合性；行为变化跑预注册场景，部署主张跑真实入口。文本断言只证合同存在；探针记录模型／上下文／样本边界。新 Skill、跨 Skill 迁移、控制器拆分、退役、安全门、发布须独立审查；审查者必须与方案和实施者不同。blocker 要修源头、增加永久防线并重验。

## 返回

返回类型／目标、行为变化、预算与例外、迁移／删除／未知入口、运行／未运行／失败／证据边界、独立审查、下一责任人与动作。只返回段结果，不决定 Issue／PR／父目标生命周期；退出。
