# 公共面门禁扫最终 git tree、allowlist 优先，既有违规逐条显式豁免

## 背景与问题（Context and Problem Statement）

Issue #56 / #62 要求 agent-system 的 GitHub 公共面有一道 fail-closed 硬门禁。2026-09-08 实施前的状态：

- `tools/public_surface_check/public_surface_check.py` 扫工作目录、跳过大于 1 MB 的文件、不打开归档、只有 secret 与 state-lab 两类规则，且没有接进任何 workflow（只有 `tests/test_public_surface_check.py` 在测它）。
- 用 `packages/mounts` 的 `assess-public-tree` 对 `origin/main`（1141 个条目）跑一遍：blocked，46 条违规——37 条本机家目录路径、4 条内网地址、1 条凭据形状（测试夹具）、4 条 `*.receipt.json`；其中一条来自 `plugins/workcoding/.../baseline.zip` 内的文件，旧扫描器根本不会打开它。

请负责人定的一件事：门禁接进 CI 时，既有的 46 条违规怎么处理，才能既 fail-closed 又不让 main 立刻变红。

## 决策驱动因素（Decision Drivers）

- 门禁必须扫最终 staged/index tree，不能被忽略文件、未跟踪文件、大文件或归档绕过（#56 用户故事 21–25）。
- 策略要可审计：每一条放行都写在仓里，看得见、能收缩。
- 不能为了让门禁变绿而批量改历史记录或重生成评测基线——那是另一件事，且会改变证据。
- 合入后 main 必须是绿的，否则门禁会被当噪音关掉。

## 考虑过的方案（Considered Options）

| 方案 | 做法 | 适用场景 | 代价 |
|---|---|---|---|
| A 先清理再接门禁 | 改写 46 处内容后再上 CI | 违规少且都是活文档 | 大部分在 `_archive/`、`work/`、旧 Change 记录里，改写等于篡改历史证据；评测 zip 得重生成 |
| B 放宽规则到当前树全过 | 去掉本机路径与内网地址规则 | 只想拦凭据 | 正好丢掉 #56 点名要拦的两类，「没有密码」又会被当成「已脱敏」 |
| C 规则不放宽，既有违规逐条显式豁免 | `contentExemptPaths` 列出三个历史目录与 8 个具体文件；豁免只免内容规则，路径、symlink、大小、归档规则照常 | 违规集中在历史与夹具、需要马上 fail-closed | 豁免清单要有人收缩；新文件放进历史目录也会被免内容检查 |

## 决定结果（Decision Outcome）

选 C（提案状态，等负责人裁定）。不选 A：改写历史证据不在 #62 授权内，也不该由门禁 PR 顺手做。不选 B：与 #56 的明示要求相反。

接入顺序，每步可单独退：

1. `packages/mounts` 的 `assess-public-tree` 与策略文件 `.github/public-tree-policy.json` 入库（可 revert）。
2. `.github/workflows/public-gate.yml` 接进 PR 与 main：先跑合成 smoke（违规 tree 必须 blocked、合规必须 allowed、缺策略必须失败），再扫 HEAD（可 revert；不在分支保护里设必需检查前不会拦合并）。
3. 负责人决定是否把 `Public tree gate` 加进分支保护的必需检查（仓库设置，不在 git 里）。
4. 之后按需收缩豁免清单：清一个文件就从清单删一行，门禁自动开始管它。

旧的 `public_surface_check.py` 不在本决定里删除：它没接 CI、不构成重复扫描；退役与否另议。

### 后果（Consequences）

- 好的：symlink、gitlink、仓外路径、归档内容、大文件从此有硬门；每条放行都在一个文件里。
- 坏的或要承担的：`_archive/`、`work/`、`openspec/changes/archive/` 三个目录下新增文件也不做内容检查——那里按 AGENTS.md 只收历史证据，但仍需负责人知情。
- 回退：revert 接入 PR；若已设必需检查，需在仓库设置里手动去掉（revert 回不去的部分）。

### 确认（Confirmation）

- workflow 在 PR 上跑出 smoke 三条 ok 与 `status: allowed (scanned N)`。
- 往任一 PR 加入一个含 `ghp_` 形状字符串的新文件，`Public tree gate` 必须失败并在输出里给出 `路径: credential (github-token)`。
- 落地后回来补：首个真实拦截的 PR 链接。
