已验证的范围仅为版本钉住的 Orca CLI 合同和结构化调度映射：runtime 证据为 ready/`1.4.192`，已知 CLI provider ID 为 `claude`、`codex`、`omp`、`pi`、`grok`，调度入口为 `orca automations create --provider <agent>`。注入的 scheduler/CLI dry-run 验证了 argv/spec 和 manifest hash，不创建真实 automation。
