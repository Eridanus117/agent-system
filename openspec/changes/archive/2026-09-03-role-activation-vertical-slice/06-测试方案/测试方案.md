# 测试计划

## 验证范围与层级

| 层级 | 目标 | 工具/入口 | 通过标准 |
|---|---|---|---|
| CLI 基础入口 | 验证 control-plane 用户入口在锁定依赖安装后可加载 | `bun install --frozen-lockfile && bun packages/control-plane/src/cli/index.ts --version`、`list` | 进程成功退出并输出版本/配置列表；`--help` 不作为既有命令前置条件 |
| Role source 合同 | 验证 Role metadata、版本、路径和内容索引 | 定向 unit tests | 无效 role.toml、越界路径和缺少内容明确失败 |
| Revision 组成 | 验证 Role → CapabilityReference → immutable revision | domain/application tests | revision 保留 Role version/source/digest，重复能力和坏引用失败 |
| Claude 装配 | 验证 instruction/skills 的 invocation-scoped 物化 | Claude adapter/materializer tests | argv、plugin 目录、内容指纹和清理结果符合合同 |
| 生命周期 | 验证 prepare/confirm/apply/observe 状态边界 | activation integration tests | 未确认不启动；失败关闭；终态可观察 |
| 真实宿主 | 验证客户端实际接收到装配 | 受控 Claude `--version`/fresh smoke | 只报告实际可观察的启动和清理，不把配置成功写成行为改善 |

## 测试环境与数据

| 资产 | 位置 | 生命周期 | 清理责任 |
|---|---|---|---|
| 最小公开 Role fixture | `06-测试方案/fixtures/role-minimal/` | 测试期间 | runner 删除临时副本 |
| 无效 Role fixtures | `06-测试方案/fixtures/invalid-*` | 测试期间 | runner 删除 |
| 临时 SQLite | 系统临时目录 | 每个测试独立 | 测试 teardown 删除 |
| Claude invocation 目录 | control-plane 状态根临时目录 | 单次 invocation | adapter finally 清理 |
| 真实 Claude binary | 测试环境 PATH | 只读探测/受控启动 | 不修改宿主配置 |

## 场景与 Requirement 覆盖

| 场景 ID | Requirement | 前置 | 输入 | 断言 | 清理 |
|---|---|---|---|---|---|
| ROLE-001 | CLI 可启动 | 锁定依赖已安装 | `--version`、`list` | 不触发 JSX runtime import error，现有入口成功退出；未知的 `--help` 不计为启动失败 | 无 |
| ROLE-002 | 读取有效 Role | 最小 fixture 合法 | `role.toml`、`memory.md`、一个 Skill | 得到稳定 identity/version/source/digest 和能力引用 | 临时 fixture |
| ROLE-003 | 拒绝无效 Role | 缺字段/非法相对路径 | invalid fixtures | 不生成 revision，不写入产品状态 | 临时 fixture |
| ROLE-004 | 生成不可变 revision | ROLE-002 通过 | Role capability refs | 新 revision 可追溯，重新 compose 不覆盖旧 revision | 临时 DB |
| ROLE-005 | Claude instructions 装配 | revision 含 instruction | instruction sourceRef | 传入 `--append-system-prompt`，无法读取时 required fail closed | invocation 目录 |
| ROLE-006 | Claude Skills 装配 | revision 含 skill | Skill sourceRef | 生成 plugin manifest/skills 目录并传入 `--plugin-dir` | invocation 目录 |
| ROLE-007 | 一次确认边界 | revision 和 plan 已准备 | 未确认/确认 | 未确认不 spawn；确认后 operation 进入 applying | 临时 DB |
| ROLE-008 | 启动观察与清理 | Claude binary 可探测 | fresh launch | 记录 observation/outcome；终态删除物化目录 | invocation 目录 |
| ROLE-009 | 既有 Session 热切换 | 已运行 operation | 新 revision apply | 结果为 `requires-restart`，不修改已有 Session | 临时 DB |
| ROLE-010 | 权限与隔离 | Role source 含项目任务或秘密 | forbidden fixture | 拒绝进入 Role source、日志和投影 | 临时 fixture |

## 自动化资产

```text
06-测试方案/
├── fixtures/
├── scenarios/
├── runtime/
└── runner/*.ts
```

优先复用 `packages/control-plane/tests/` 的 Bun test、现有 adapter fixture 和 SQLite 临时数据库。真实 Claude smoke 必须显式标记宿主版本、客户端参数、启动结果和清理结果；不得用 fake adapter 替代真实宿主证据。

## 失败与停止条件

- workspace 依赖未安装时先执行 `bun install --frozen-lockfile`；不能把依赖环境问题误写成源码修复完成。
- Role source 解析失败、路径越界、秘密或项目状态混入时停止。
- required capability 无法物化时停止启动，不生成部分成功。
- plan hash、revision id、client id 或 operation id 不一致时停止 apply。
- 真实宿主不可用时可完成结构测试，但验收结论不得声称实际生效。
- 发现全局配置、Role source 或已有项目文件被改写时停止并回滚临时产物。

## 验收证据

每次运行使用独立 `runs/<run-id>/`，保存 commit、依赖版本、输入 Role digest、测试输出、宿主 probe、invocation 清理和未验证边界。失败输出不得覆盖；没有真实宿主运行，不填写实际行为 PASS。
