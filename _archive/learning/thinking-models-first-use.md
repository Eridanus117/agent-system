# 思维模型全景地图：首轮消费闭环

> **定位**：这是关联 [#166（个人学习与 KB 内容）](https://github.com/Eridanus117/agent-control/issues/166)B1 的一次首轮消费入口，
> 用来把已经入库的思维模型地图变成一次可完成、可反馈的真实浏览。
> 它不新增概念，不记录“已掌握”，也不把概念升级成 Agent 默认方法。
>
> **资产入口**：
> [81 项思维模型与方法全景地图](https://github.com/Eridanus117/private-kb/blob/d9ca20c1900afce01506b18f8081c2539a32a6e8/sources/thinking/INDEX.md)；
> 需要更深的适用与禁用边界时再看
> [K21 可浏览思考工具箱](../_archive/knowledge/thinking-toolkit.md)。

## 本轮完成定义

用 20–30 分钟完成以下四个可观察结果：

1. 浏览全景地图的六个分类，知道每类大致收了什么；
2. 选出 3 个“以前不知道、理解模糊或现在值得用”的条目；
3. 把其中 1 个条目用于一个真实问题，并写下一条它改变了什么；
4. 对地图给出“有用／需调整／暂停”之一的反馈。

四项都产生后，本轮才算消费完成。浏览文件、读完条目或觉得“好像懂了”都不单独算完成。

## 20–30 分钟流程

### 1. 先写真实问题（2 分钟）

只写一句：

> 我现在最想改善的判断、沟通、学习或问题求解是：______。

若当前没有真实问题，也可以把“我想先知道这个领域里有什么”作为本轮问题；此时不强行做复杂应用。

### 2. 浏览六类入口（8–10 分钟）

先只看全景入口的分类、条目名和每项 1–3 句说明，不追外链，不做笔记大全。每类最多标一个候选：

- 决策与不确定性；
- 认知偏差与判断；
- 系统思维与战略；
- 沟通与论证；
- 问题求解与创造；
- 学习与记忆。

遇到有趣条目时先标记，继续完成六类扫描；本轮目标是建立方位感，不是一次学完整张地图。

### 3. 收敛为三个候选（3–5 分钟）

从标记中只留 3 个，每个补一句理由：

| 候选 | 我为什么以前没看见或现在值得用 |
| --- | --- |
| 1. ______ | ______ |
| 2. ______ | ______ |
| 3. ______ | ______ |

优先保留能改变真实问题的条目；只有新奇、但暂时不会改变任何判断的条目留在“以后再看”。

### 4. 对一个真实问题做最小应用（7–10 分钟）

从三个候选里选 1 个，按下面四句完成一次最小应用：

1. **原判断**：在使用这个模型前，我倾向于 ______；
2. **模型追问**：它要求我额外检查 ______；
3. **新证据或新角度**：我因此看见 ______；
4. **结果**：我的下一步保持不变／改为 ______，因为 ______。

若条目在 K21 中，先读那里的“是什么／最有用／别用”三项再应用；若不在 K21，只把全景条目当检索入口，真正采取高影响行动前回到其一手来源核对边界。

### 5. 留下消费回执（3 分钟）

复制下面模板，交给当前协调者或填入关联 [#187（个人知识库广度建材）](https://github.com/Eridanus117/agent-control/issues/187)的验收面：

```text
思维模型地图首轮反馈
- 形态：有用／需调整／暂停
- 本轮真实问题：
- 新发现的 3 个条目：
- 实际应用的 1 个条目与变化：
- 导航最需要调整的一处：
- 我下一次最想浏览或深挖的域（可留空）：
```

只有负责人实际提交这份回执，才产生“负责人已经使用”的证据；本文交付本身只证明消费入口已经实现。

## 三层分工

| 需要 | 去哪里 | 不承担什么 |
| --- | --- | --- |
| 先知道“有什么” | 81 项全景地图 | 不证明条目对当前问题有效 |
| 深看精选概念的适用、禁用与本仓例子 | K21 可浏览思考工具箱 | 不触发 Agent 行动，不记录掌握状态 |
| 让 Agent 在任务中执行一种方法 | APS 方法登记面 | 不替代负责人的学习与产品决定 |

概念进入地图或 K21，不产生授权、写入所有权、产品采用或 APS 默认触发资格。需要 Agent 执行时，仍由 APS 先判断普通路径是否足够、当前瓶颈是什么以及具体方法的同意与风险门。

## 停止与调整信号

- 扫描 10 分钟仍找不到一个与真实问题相关的条目：停止本轮，反馈“导航或选域不匹配”；
- 为完成流程而同时套用多个模型：退回只选一个；
- 条目只有名字吸引人，但找不到会改变的判断：保留为候选，不强行应用；
- 本流程本身比临时搜索更费力，且连续两次没有带来新角度：暂停该消费形态；
- 需要检查保持、复习或掌握状态：那属于关联 [#174（Route B 教学系统采纳）](https://github.com/Eridanus117/agent-control/issues/174)曾验证的教学循环边界，不在本轮扩张。

## 证据边界与下一步

本页只把已存在资产接成一次可运行的消费路径，当前证据最多支持“实现完成”。是否真正帮助负责人建立方位感、找到有用模型或节省检索时间，要由首轮回执验证；没有回执时，不把它写成当前交付验收、样本有效或产品采用。

首轮若为“有用”，下一步只按回执中的一个明确需求深化；若为“需调整”，先修导航或说明；若为“暂停”，保留全景地图作为按需参考，不继续制造学习流程。
